# ConnectX Academy — `/academy` 페이지 기획

## 대상 페이지

`/academy` (ConnectX Academy 브랜드 유닛 상세 페이지)

## 목적

- 잠재 수강생(인프라/보안 취업준비생, 주니어~미들 엔지니어, 커리어 전환자)과
  기업 교육 담당자 양쪽에게 Academy가 "이론이 아니라 실무로 이어지는 교육"
  이라는 신뢰를 주고, 과정 문의/상담 신청으로 전환시킨다.
- 랜딩 페이지 카드는 유닛명·connect phrase만 보여주는 티저이므로, 이 페이지는
  "왜 지금 인프라/보안 교육이 필요한지 → Academy는 무엇을 다르게 하는지 →
  구체적으로 무엇을 배우는지 → 어떻게 시작하는지"까지 내려가는 설득 흐름을
  담당한다.

## 핵심 메시지

**"지식만 가르치지 않는다. 지식ㆍ실무ㆍ사람을 연결해 현장에서 바로 쓰게
만든다."**

- 인프라/보안은 자격증·이론 지식과 실제 현업 요구 사이의 괴리가 큰 분야다.
  Academy는 그 괴리를 메우는 다리 역할을 한다.
- 3개 연결 축:
  1. **지식**: 인프라/보안 기본기부터 최신 위협/기술까지의 커리큘럼
  2. **실무**: 현업에서 실제로 쓰는 도구·절차·사례 기반 실습
  3. **사람**: 강사·동기·선배 실무자와의 네트워크 — 수료 후에도 이어지는 연결

## 정보구조 (섹션 순서)

1. Hero
2. 문제 제기 — 왜 지금 인프라/보안 교육이 필요한가
3. Academy가 연결하는 것 (지식ㆍ실무ㆍ사람 3축 설명)
4. 배우는 방식 — ConnectX 4단계 프로세스를 교육에 적용
5. 과정/트랙 안내
6. 대상별 안내 (개인 수강생 / 기업 교육 담당자 — 2트랙 탭 또는 2단 구성)
7. 강사진 및 신뢰 요소
8. FAQ
9. CTA — 상담/문의

## 섹션별 카피 초안

### 1. Hero

- 상단 라벨: `인프라/보안 교육`
- 타이틀: **ConnectX Academy**
- 서브 카피(1문장, connect phrase 확장): "지식ㆍ실무ㆍ사람을 연결해,
  자격증이 아니라 실전에서 통하는 인프라/보안 역량을 만듭니다."
- CTA 버튼 2개: `[커리큘럼 살펴보기]` (섹션 5로 스크롤) / `[상담 신청하기]`
  (섹션 9로 이동 또는 문의 폼)

### 2. 문제 제기

- 소제목: "이론은 많은데, 실무는 왜 늘 낯설까요"
- 바디 카피(예시, 최종 문구는 검증 필요):
  - "자격증 커리큘럼은 실제 장애 대응, 보안 사고 대응과 거리가 있습니다."
  - "혼자 독학하기엔 무엇부터 봐야 할지, 지금 배우는 게 현업에서 통하는지
    확인할 방법이 없습니다."
  - "기업 입장에서도 신입/재직자를 어디까지, 어떻게 교육해야 실무 투입이
    빨라지는지 기준이 없습니다."
- 이 섹션은 리스트 3~4개 카드 형태 제안 (개인 관점 페인포인트 2개 + 기업
  관점 페인포인트 1~2개를 섞어, 아래 6번 섹션의 2트랙 구성을 미리 암시)

### 3. Academy가 연결하는 것

- 소제목: "지식ㆍ실무ㆍ사람, 세 가지를 함께 연결합니다"
- 3열 카드:
  - **지식 연결**: "인프라 운영과 보안 실무의 기본기부터 최신 위협
    대응까지, 흩어진 지식을 체계적인 커리큘럼으로 정리합니다."
  - **실무 연결**: "이론 강의가 아니라 실제 장비/환경/사례를 다루는 실습
    중심으로 설계합니다. 배운 것이 바로 현업에서 통하도록."
  - **사람 연결**: "현업 강사, 함께 배우는 동료, 선배 수료생까지 —
    수료 이후에도 이어지는 실무자 네트워크를 만듭니다."

### 4. 배우는 방식 (마스터 브랜드 4단계 적용)

- 소제목: "ConnectX의 진단 → 큐레이션/설계 → 실행 → 지속관리, Academy에서는
  이렇게 이어집니다"
- 4단계 카피:
  1. **진단**: "현재 역량과 목표(취업/이직/재직자 역량강화)를 먼저
     확인합니다."
  2. **큐레이션/설계**: "목표에 맞는 과정과 순서를 설계합니다 — 필요한
     것만, 필요한 순서로."
  3. **실행**: "실습 중심 교육을 진행합니다."
  4. **지속관리**: "수료 후에도 커뮤니티/후속 학습으로 역량을 이어갑니다."
- 랜딩 페이지 Hero의 4단계 프로세스를 재활용하는 섹션이므로, 시각적으로
  랜딩과 연결되어 있음을 알 수 있게(동일한 스텝 UI 재사용) 개발팀에 전달.

### 5. 과정/트랙 안내

- 소제목: "과정 안내"
- **[콘텐츠 갭 — 확인 필요]** 실제 커리큘럼 과목명/커리큘럼표는 사업 측
  자료가 없어 이 기획 문서에는 포함하지 못했다. 아래는 도메인
  ("인프라/보안 교육")에서 통상적으로 다루는 영역을 예시로 제안한
  placeholder이며, 실제 과정명/차수/커리큘럼은 사업 담당자 확인 후
  교체가 필요하다.
  - 예시 트랙 카테고리(가안): 인프라 운영 기초, 클라우드 인프라, 네트워크
    보안, 보안 관제/침해대응, 컴플라이언스/보안관리체계
- 개발 단계에서는 이 섹션을 "과정 카드 리스트" 컴포넌트로 만들되, 실제
  콘텐츠가 확정될 때까지는 카드 3~4개 정도의 자리표시(placeholder) 데이터로
  구현하는 것을 권장.

### 6. 대상별 안내

- 소제목: "누구를 위한 과정인가요"
- 2단 구성:
  - **개인 수강생**: "인프라/보안 분야로 취업·이직을 준비 중이거나, 현재
    업무 역량을 실무 수준으로 끌어올리고 싶은 분."
  - **기업 교육 담당자**: "신입/재직자 인프라·보안 교육을 위탁하고 싶은
    기업, 팀 단위 역량강화가 필요한 조직." → 이 카드는 Advisory의
    "전담 인프라·보안 책임자를 채용하기 어려운 기업" 타깃과 자연스럽게
    겹치는 지점이므로, 카드 안에 `[Advisory 살펴보기]` 크로스링크를 넣는
    것을 제안 (Academy 수강 기업이 Advisory 잠재고객으로 이어지는 동선).

### 7. 강사진 및 신뢰 요소

- 소제목: "현업이 가르칩니다"
- **[콘텐츠 갭 — 확인 필요]** 실제 강사 프로필/경력/실적 데이터 없음.
  placeholder 카피: "현직 인프라/보안 실무자가 직접 설계하고 강의합니다."
  개발 시 강사 소개 카드(사진/경력/담당 과정) 컴포넌트를 만들되 실데이터는
  추후 채움.

### 8. FAQ

- 예시 질문 3~4개 (최종 문구는 실제 운영 방식 확정 후 조정):
  - "온라인/오프라인 중 어떤 방식인가요?"
  - "선수 지식이 없어도 들을 수 있나요?"
  - "기업 단체 교육도 가능한가요?"
  - "수료 후 취업/이직 연계가 있나요?"

### 9. CTA

- 소제목: "지금 상담을 신청하세요"
- 바디: "어떤 과정이 나에게 맞는지, 우리 조직에 필요한 교육은 무엇인지
  먼저 진단해드립니다."
- 버튼: `[무료 상담 신청]` / 보조 링크: `[커리큘럼 자료 요청]`

## 톤앤매너 메모

- 사이트 기본 톤(전문적/신뢰감 우선, decisions.md)을 따르되, Advisory보다는
  상대적으로 접근하기 쉬운 어조를 사용한다 — 대상이 예비 수강생 개인을
  포함하기 때문. "가르친다"보다 "함께 실무 역량을 만든다"는 어조.
- 과장된 취업/합격 보장 표현은 피한다 (실제 취업 연계/합격률 데이터가
  확인되지 않은 상태이므로, FAQ의 "취업/이직 연계" 답변도 실데이터 확인
  전에는 확정적 문구를 넣지 않는다).
- 커리큘럼/강사 섹션은 이 문서에서 실제 콘텐츠를 채우지 못한
  placeholder임을 개발팀에 명확히 전달 — 다음 스펙에서 실데이터가 오기
  전까지는 "예시 자리표시" UI로 구현할 것.
- Academy → Advisory 크로스링크(6번 섹션)는 3개 브랜드 유닛이 하나의
  ConnectX 사이트 하위 섹션이라는 site scope 결정(decisions.md)을 살리는
  장치로 제안한 것이며, 필수 요구사항은 아니다.
