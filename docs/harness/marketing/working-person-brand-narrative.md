# "일하는 사람" 브랜드 연계 서사 반영

사용자가 외부에서 작성한 `ConnectX_브랜드_연계전략_및_홈페이지_문구제안.md`를 공유,
Academy/Advisory/Wellness를 "일하는 사람"(career growth + stable work + daily
health) 관점으로 연결하는 문구 제안을 홈페이지에 반영 요청.

## 채택한 것

문서 제안 거의 그대로 반영:
- 홈 Hero 설명 문구 (메인 타이틀+설명 통합)
- BentoSection 카드 3개의 타이틀/설명/버튼 라벨 전체 교체
- "세 가지가 서로를 연결합니다" → "성장하는 일에도, 건강한 일상에도 필요한 연결"
  섹션으로 전면 교체 (헤딩/인트로/3개 카드 문구 전부)
- Wellness Hero 설명 문구
- Footer 브랜드 소개 문구
- 홈 FAQ "ConnectX는 어떤 회사인가요?" 답변 — 기존 "같은 사람들의 신뢰" 서사와
  새 "일하는 사람" 서사가 한 페이지에서 충돌하지 않도록 함께 교체

## 기존 구조와 맞춘 조정

- **홈 Hero H1("연결이 만드는 변화")은 그대로 유지** — Figma에서 가져온 핵심
  비주얼 아이덴티티(teal 강조 스타일링 포함)라 임의 교체 대신, 문서가 제안한
  "메인 타이틀+설명 문구"는 통합해서 서브 문단으로 반영.
- **Wellness Hero H1("ConnectX Wellness")도 브랜드명 그대로 유지** — Academy/
  Advisory와 동일하게 H1=브랜드명 패턴을 깨지 않기 위함(2026-09-30 Advisory
  명칭 변경 때 정한 패턴과 일관). 문서의 감성적 헤드라인("일을 챙기는 당신...")
  은 subtitle 문단에 통합.
- **LoopSection의 "앞으로의 방향"(Advisory 보안 역량 → Wellness 건강데이터 보호
  확장) 콜아웃은 유지** — 문서가 다루지 않은 내용이지만 사업계획서 근거가
  남아있는 별개의 유효한 장기 비전이라 서로 배치되지 않아 보존. 문서가 제안한
  "현재 3가지 연결" 서사로 3개 카드 본문만 교체.
- BentoSection의 기존 `tag`(실무 교육 프로그램 등 작은 보조 라벨)는 문서
  범위 밖이라 유지, `linkLabel`만 신규 추가해 "자세히 보기" → 서비스별 구체
  라벨로 교체.

## 문서 7번("현재 vs 계획 구분") 반영 — 범위 확장

문서가 Wellness의 "전문가 검수/데이터 기반 추천/섭취 기록 관리" 류 표현이
사업계획서 기준 미래 단계(2~3년차) 계획인데 현재형으로 읽힌다고 지적. 점검
결과 지난 세션에서 다 못 잡은 잔여 표현 4곳 추가 발견·수정:
- connectAxes "데이터 연결" 축 본문
- process "큐레이션/설계"·"지속관리" 단계 본문
- FAQ "추천이 마음에 안 들면" 답변
- trust 포인트 "먹는 것을 계속 기록하고 관리합니다"

전부 "자동 추적·재추천 시스템이 있다"는 뉘앙스를 "필요하면 언제든 다시
문의해 안내받을 수 있다"는, 지금 실제로 가능한 수준(이메일 상담)으로
낮춰서 수정 — 2026-10-01 "콘텐츠 갭 처리 원칙"과 동일한 기준 적용.
