# ConnectX Wellness — `/wellness` 페이지 기획

## 대상 페이지

`/wellness` (ConnectX Wellness 브랜드 유닛 상세 페이지)

## 목적

- 건강기능식품을 "누구에게 물어봐야 할지 몰라 대충 사는" 소비자에게,
  Wellness가 전문가와 데이터를 통해 나(혹은 부모님)에게 맞는 제품을 골라
  주는 신뢰 가능한 위탁판매 채널임을 알리고, 맞춤 추천/상담 신청 또는
  구매 전환으로 이어지게 한다.
- 타깃이 명시적으로 두 그룹(부모님, 직장인)이므로, 이 페이지는 하나의
  메시지를 모두에게 던지기보다 두 페르소나의 상황을 각각 구체적으로
  보여주는 것이 랜딩 카드 대비 가장 크게 "더 깊이 들어가는" 지점이다.

## 핵심 메시지

**"어떤 영양제를 먹어야 할지, 전문가와 데이터가 대신 골라드립니다."**

- 3개 연결 축 (connect phrase 확장):
  1. **건강**: 각자 다른 몸 상태, 생활 습관, 걱정거리
  2. **전문가**: 광고성 정보가 아닌 전문가 검수/추천
  3. **데이터**: 체크리스트·기록 기반으로 시간이 지나도 계속 맞춰가는 개인화
- Wellness는 "위탁판매" 모델임을 카피 전반에서 은근히 인지해야 한다 — 자체
  제조/브랜드를 내세우기보다 "정확한 제품을 정확한 사람에게 연결하는
  큐레이터/셀렉트샵"이라는 포지션이 카피의 축이 된다.

## 정보구조 (섹션 순서)

1. Hero
2. 문제 제기 — 영양제 선택이 왜 어려운가
3. Wellness가 연결하는 것 (건강ㆍ전문가ㆍ데이터 3축)
4. 타깃별 시나리오 — 부모님 / 직장인 (2단 구성)
5. 이용 흐름 — ConnectX 4단계를 웰니스 서비스에 적용
6. 제품 카테고리 안내
7. 신뢰 요소 (전문가 검수, 데이터 기반 근거, 파트너사/제품 안전성)
8. FAQ
9. CTA — 맞춤 추천 받기 / 상담·구독 신청

## 섹션별 카피 초안

### 1. Hero

- 상단 라벨: `건강기능식품 위탁판매`
- 타이틀: **ConnectX Wellness**
- 서브 카피: "건강ㆍ전문가ㆍ데이터를 연결해, 나에게 맞는 영양제를 정확하게
  찾아드립니다."
- CTA: `[내 맞춤 추천 받기]` / `[제품 카테고리 보기]`

### 2. 문제 제기

- 소제목: "영양제, 아무거나 드시고 계신가요"
- 바디 카피(예시):
  - "광고에서 본 제품과 내 몸에 필요한 제품은 다를 수 있습니다."
  - "부모님 영양제를 사드리고 싶은데, 무엇부터 챙겨야 할지 모르겠습니다."
  - "매일 바쁜 직장인은 피로, 눈 건강, 면역 중 뭐가 먼저인지조차 따져볼
    시간이 없습니다."
- 카드 3개 정도로, 아래 4번 타깃별 섹션의 두 페르소나(부모님/직장인)를
  이 단계에서 미리 암시하는 것을 제안.

### 3. Wellness가 연결하는 것

- 소제목: "건강ㆍ전문가ㆍ데이터를 연결합니다"
- 3열 카드:
  - **건강 연결**: "지금의 몸 상태와 생활 습관에서 출발합니다. 유행하는
    성분이 아니라 내게 필요한 것부터."
  - **전문가 연결**: "전문가가 검수한 제품과 정보만 안내합니다. 광고가
    아니라 근거."
  - **데이터 연결**: "한 번의 추천으로 끝나지 않습니다. 기록을 바탕으로
    계속 맞춰가며 필요할 때 다시 챙깁니다."

### 4. 타깃별 시나리오

- 소제목: "이런 분들께 필요합니다"
- 2단 구성 (각 카드에 상황 + 제안 한 줄):
  - **부모님을 위해**: "직접 챙겨드리기 어려운 부모님 건강, 무엇을 먼저
    챙겨야 할지 몰라 미루고 계셨다면. 나이대와 상태에 맞는 제품을 대신
    골라드립니다." (자녀가 선물/구독하는 시나리오, 또는 부모님 본인이
    이용하는 시나리오 둘 다 열어둔 문구)
  - **직장인을 위해**: "피로, 스트레스, 면역 — 다 챙기고 싶지만 시간이
    없는 직장인을 위해. 지금 가장 필요한 것부터 순서대로 안내합니다."
- 이 섹션은 랜딩 카드에는 전혀 없던 내용이므로, 상세 페이지가 카드 블러브
  대비 "더 깊이 들어간다"는 요구를 가장 직접적으로 충족하는 섹션이다.

### 5. 이용 흐름 (마스터 브랜드 4단계 적용)

- 소제목: "진단 → 큐레이션/설계 → 실행 → 지속관리"
- 4단계 카피:
  1. **진단**: "간단한 체크리스트로 지금 몸 상태와 생활 습관을 확인합니다."
  2. **큐레이션/설계**: "전문가와 데이터를 바탕으로 맞춤 제품 조합을
     구성합니다."
  3. **실행**: "구성된 제품을 편하게 받아보실 수 있도록 연결합니다."
  4. **지속관리**: "섭취 기록과 변화에 맞춰 다음 추천을 계속 업데이트합니다
     (재구매/구독 알림 포함 가능)."

### 6. 제품 카테고리 안내

- 소제목: "카테고리별로 살펴보기"
- **[콘텐츠 갭 — 확인 필요]** 실제 취급 제품/파트너사 리스트는 사업 자료
  없음. 일반적인 건강기능식품 카테고리를 placeholder로 제안:
  - 면역, 피로회복/활력, 눈 건강, 장 건강, 뼈/관절, 수면/스트레스
- 개발 시 카드 그리드로 구현하되, 실제 취급 제품군이 확정되면 교체 필요.
  ("위탁판매" 특성상 취급 브랜드/제품 목록이 자주 바뀔 수 있으므로,
  하드코딩보다 추후 데이터 소스 분리를 고려하도록 개발팀에 참고 전달.)

### 7. 신뢰 요소

- 소제목: "믿고 선택하는 이유"
- **[콘텐츠 갭 — 확인 필요]** 실제 전문가 프로필, 검수 기준, 파트너사
  안전 인증 정보 없음. placeholder 카피:
  - "전문가가 검수한 제품만 소개합니다" / "광고비가 아니라 필요에 따라
    추천합니다" / "먹는 것을 계속 기록하고 관리합니다"
- 건강기능식품은 신뢰/근거 표시가 소비자 전환에 중요한 영역이므로, 이
  섹션도 Advisory의 신뢰 요소 섹션과 마찬가지로 실데이터 확인이 다음
  스펙의 선행 조건임을 명시.

### 8. FAQ

- 예시 질문:
  - "직접 제조하는 제품인가요?" → 위탁판매 모델을 솔직하게 설명하는 질문
    (신뢰를 위해 회피하지 않는 것을 권장)
  - "부모님 것도 대신 신청할 수 있나요?"
  - "정기 구독도 가능한가요?"
  - "추천이 마음에 안 들면 바꿀 수 있나요?"

### 9. CTA

- 소제목: "지금 내 맞춤 추천을 받아보세요"
- 바디: "1분 체크리스트로 시작합니다. 나에게, 혹은 부모님께 필요한 것부터
  안내해드립니다."
- 버튼: `[맞춤 추천 시작하기]` / 보조 링크: `[뉴스레터/소식 구독]`

## 톤앤매너 메모

- 사이트 기본 톤(전문적/신뢰감 우선, decisions.md)은 유지하되, Wellness는
  3개 유닛 중 유일하게 일반 소비자(B2C)를 직접 상대하므로 그 안에서 가장
  따뜻하고 친근한 변주를 준다 — Advisory의 격식 있는 어조와 대비되는
  지점. 다만 "전문가/데이터"라는 신뢰 축은 카피에서 계속 유지해, 친근함이
  가벼움으로 흐르지 않도록 한다.
- 부모님 페르소나는 "자녀가 부모님을 위해 챙긴다"와 "부모님 본인이
  이용한다" 두 경우를 모두 열어두는 문구를 쓴다 (실제 주 사용자층이 어느
  쪽인지는 확인되지 않았으므로 카피 단계에서 단정하지 않음).
- 건강기능식품은 과장 광고/의학적 효능 단정 표현에 대한 규제 리스크가
  있는 영역이다. "치료", "완치", "질병 예방" 등 의약품 오인 표현은
  피하고, 톤앤매너뿐 아니라 실제 카피 검수 단계에서 법무/컴플라이언스
  확인이 필요하다는 점을 개발팀/사업 담당자에게 전달.
- 위탁판매 모델임을 숨기지 않는다 (FAQ 1번) — 직접 제조가 아니라는 점을
  솔직히 밝히되, 그것이 오히려 "여러 브랜드 중 전문가가 고른다"는
  큐레이션 신뢰로 이어지도록 프레이밍한다.
